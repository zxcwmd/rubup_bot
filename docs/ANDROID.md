# Второй Android-телефон как исполнитель (Termux-альтернатива)

> Это прежняя альтернативная схема. Если нужен самостоятельный APK без Termux/proot, используйте [нативный RubUP Worker для Android 10+](ANDROID_APK.md): он сам выполняет работу на рабочем телефоне и управляется через Telegram с основного телефона.

## Схема

```text
Основной телефон                         Второй Android-телефон
Telegram-клиент                          Termux
  ├─ кнопки/команды                        └─ Ubuntu 24.04 arm64 в proot
  ├─ отправка картинок боту                   ├─ Python 3.11+
  └─ получение data/links.txt                 ├─ Playwright Chromium
                                              ├─ SQLite и библиотека картинок
                                              └─ Telegram-бот (длинный процесс)
```

Основной телефон нужен только для обычного Telegram-клиента. Весь Chromium, SQLite и публикации находятся на втором телефоне. Отдельная веб-панель не нужна.

> **Статус проверки:** код, установочные скрипты и автоматические тесты подготовлены, но запуск на физическом Android с реальными Chromium/TikTok пока не выполнялся. Сначала проверьте один комментарий с минимальными лимитами. Не считайте схему гарантированной работой 24/7.

## Требования и ограничения

- Рекомендуется 64-битный телефон `arm64`, желательно Android 10+ и от 4 ГБ RAM. Нужно примерно 3–5 ГБ свободного места для Ubuntu, Python и Chromium.
- Android root не нужен. Playwright запускается **в Ubuntu proot**, а не напрямую в Termux.
- Termux ставьте из официального репозитория GitHub или F-Droid. Для интерактивного входа понадобится VNC-клиент, например AVNC.
- TikTok должен разрешать фото в комментариях для этого аккаунта/региона и показывать веб-интерфейс без капчи. Бот не обходит капчу.
- Сеть телефона должна открывать и TikTok, и `api.telegram.org`. При блокировках проверьте другую сеть и системный VPN на Android-исполнителе.
- Android может выгружать Termux в фоне. Питание, wake lock и настройки батареи обязательны, но не дают абсолютной гарантии непрерывной работы.
- **Запускайте только одного исполнителя.** Не запускайте одновременно `run` на ПК и Android с одним Telegram-токеном. Основной телефон не должен запускать второй экземпляр бота.

## 1. Подготовьте Termux на втором телефоне

Откройте Termux и выполните:

```bash
pkg update -y && pkg upgrade -y
pkg install -y proot-distro git curl nano
proot-distro install ubuntu:24.04
proot-distro login ubuntu
```

Последняя команда открывает shell Ubuntu. Дальнейшие команды до выхода выполняются **внутри Ubuntu**, не в обычном Termux.

## 2. Скачайте и установите проект

```bash
cd
git clone --branch arena/514c6f72-rubup-bot --single-branch https://github.com/zxcwmd/rubup_bot.git
cd rubup_bot
chmod +x scripts/*.sh scripts/android/*.sh
bash scripts/android/install.sh
```

Установщик:

1. ставит Python, venv, Xvfb, Openbox и x11vnc;
2. создаёт `.venv` и устанавливает зависимости;
3. скачивает Playwright Chromium и его Linux-библиотеки;
4. создаёт `.env`, `data/`, `images/` и другие рабочие папки.

Не переносите `.venv` с Windows или ПК: её нужно создавать заново на Android. База `data/` и браузерный профиль также должны принадлежать одному исполнителю.

## 3. Настройте `.env`

```bash
nano .env
```

Минимум:

```dotenv
TELEGRAM_BOT_TOKEN=токен_от_BotFather
ADMIN_USER_IDS=ваш_числовой_Telegram_ID
TIKTOK_USERNAME=точный_логин_TikTok_без_собаки
LINKS_FILE=data/links.txt
MAX_ACTIONS_PER_CYCLE=1
MAX_COMMENTS_PER_DAY=1
MAX_REPLIES_PER_DAY=1
```

После успешного теста лимиты можно изменить и перезапустить процесс. `scripts/android/start.sh` сам задаёт `HEADLESS=true`, поэтому для ежедневного запуска дисплей не требуется.

## 4. Первый вход в TikTok через локальный VNC

1. В Ubuntu выполните:

   ```bash
   bash scripts/android/login.sh
   ```

2. Не завершая Termux, переключитесь в AVNC и создайте подключение:
   - адрес: `127.0.0.1`;
   - порт: `5900`;
   - пароль: пусто.
3. В открывшемся экране Chromium войдите в один TikTok-аккаунт и вручную пройдите проверку безопасности, если она появилась.
4. Вернитесь в Termux и нажмите Enter, как просит команда входа.
5. Закройте VNC-экран:

   ```bash
   bash scripts/android/vnc-stop.sh
   ```

x11vnc слушает только localhost второго телефона; не пробрасывайте порт 5900 в интернет. Сессия TikTok сохраняется в `data/browser-profile`.

## 5. Запустите исполнителя

```bash
bash scripts/android/start.sh
```

Оставьте этот процесс работать. В отдельной сессии **обычного Termux** (не обязательно Ubuntu) включите wake lock:

```bash
termux-wake-lock
```

В настройках Android разрешите Termux фоновую работу и установите неограниченное использование батареи. Для длительной работы держите телефон на зарядке. Для остановки процесса сначала используйте Telegram-кнопку **⛔ Стоп**, затем при необходимости завершите `run` сочетанием Ctrl+C.

## 6. Управление с основного телефона

1. Откройте того же Telegram-бота и отправьте `/start`.
2. Нажмите **✅ Мой TikTok**, затем **📊 Статус**.
3. Отправляйте изображения боту прямо с основного телефона:
   - как фото — Telegram может сжать исходник;
   - как документ/файл — исходный JPG/JPEG/PNG/WEBP сохраняется без Telegram-сжатия.
4. Бот скачивает файл на второй телефон в `images/`, проверяет SHA-256 и не выдаёт одно содержимое дважды.
5. Нажмите **▶️ Авто** и проследите первую цепочку: фото-комментарий → лайк своего комментария → сохранение ссылки.
6. Кнопка **🔗 Ссылки** или `/links` отправляет актуальный `data/links.txt` в Telegram.
7. **⛔ Стоп** немедленно запрещает новые действия, ждёт текущий браузерный вызов и закрывает Chromium. После неё запуск только через **▶️ Авто**.

## Если что-то не работает

- Повторная диагностика в Ubuntu:

  ```bash
  cd /root/rubup_bot
  .venv/bin/python -m rubup_bot doctor
  .venv/bin/playwright install-deps chromium
  ```

- Если Chromium не виден в AVNC, проверьте `/tmp/rubup-bot-vnc/*.log` и повторите `vnc-stop.sh`, затем `login.sh`.
- Если кнопка фото или лайка не найдена, действие переходит в ручную проверку. Ссылка до подтверждённого лайка не сохраняется. После ручного лайка используйте карточку **«Проверить лайк ещё раз»** или `/retry_like ID`.
- При сетевых ошибках TikTok/Telegram проверьте доступность сайтов в обычном браузере второго телефона, DNS, системный VPN и другую сеть. Расширения обычного Android-браузера не действуют на Playwright Chromium.
- Если Android убил Termux, откройте Ubuntu снова и запустите `scripts/android/start.sh`. Не запускайте второй процесс, пока старый ещё жив.
